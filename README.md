# 地图设置调整器（Map Settings Tuner）

在游戏运行中随时修改地图设置与地图生成设置。请注意：地图生成的改动只对新生成的区块生效。

## 功能

- 修改敌人扩张、进化与污染设置。
- 修改和平模式。
- 修改当前地表的地图生成设置（资源、地形、悬崖、敌人、起始区域、地图类型与种子）。
- 一键应用地图生成预设（富矿、马拉松、死亡世界、铁路世界、带状世界等）。
- 所有修改仅限管理员操作。

## Factorio 版本

本模组适用于 Factorio 2.1。

在 Factorio 2.1 中，进化因子按地表分别存储。因此界面中填写的进化因子只会应用到玩家当前所在的地表。

# Map Settings Tuner

Allows you to change your map and map generation settings at any time you want. Note that map generation changes only apply to new chunks.

## Features

- Change enemy expansion, evolution and pollution settings of a running game.
- Change peaceful mode.
- Change map generation settings (resources, terrain, cliffs, enemies, starting area, map type/seed) of the current surface.
- Apply one of the map generation presets (Rich Resources, Marathon, Death World, Rail World, Ribbon World).
- All changes are restricted to admins.

## Factorio version

This version is updated for Factorio 2.1.

In Factorio 2.1 the evolution factor is stored per surface. The evolution factor entered in the GUI is therefore applied to the surface the player is currently on.
