Version: 1.0.0
Date: 2026-11-23
  Major Features:
    - 模组更名为“地图设置调整器”（内部名称 MapSettingsTuner）。
      Renamed the mod to "Map Settings Tuner" (internal name MapSettingsTuner).
    - 适配 Factorio 2.1。
      Updated to Factorio 2.1.
    - 新增简体中文本地化，英文仍然可用。
      Added Simplified Chinese localization; English is still supported.
    - 地图生成设置现在根据当前地表实际存在的自动放置控件生成，太空时代各星球的专属控件不会再导致报错。
      Map generation settings are now built from the autoplace controls that exist on the current surface, so planet specific controls (Space Age) no longer cause errors.
    - 水域设置改用 2.1 的水域自动放置控件，不再使用已移除的 terrain_segmentation 与 water 字段。
      Water settings now use the 2.1 water autoplace control instead of the removed terrain_segmentation and water fields.
    - 实体的自动放置设置与地块的自动放置设置保持同步，确保应用的改动真正生效。
      Per entity and tile autoplace settings are kept in sync so applied changes always take effect.
    - 进化因子按地表分别应用，符合 2.1 API 的要求。
      Evolution factor is applied per surface, as required by the 2.1 API.
    - 移除气候（湿度/辅助）设置；在 2.1 中它们属于噪声表达式，由地图类型选择器处理。
      Removed climate (moisture/aux) settings; in 2.1 these are noise expressions and are handled by the map type selector.
    - 界面样式适配 2.1。
      Updated GUI styles for 2.1.
  Bugfixes:
    - 修复“虫族扩张”中最小/最大队伍规模显示“Unknown key”的问题（2.1 已移除原版对应的本地化键，现改用模组内置文本）。
      Fixed "Unknown key" for the minimum/maximum expansion group size labels (2.1 removed the vanilla locale keys, so the mod now ships its own text).
    - 修复太空时代星球（例如祝融星）的资源列表重复显示同一资源的问题，例如出现两个“煤矿”。
      Fixed duplicated resource rows on Space Age planets (for example Vulcanus showing two Coal entries).

      Original mod "Change Map Settings" created and developed by Bilka (last upstream version 5.0.1, MIT license).
    - 2.1 适配由 Gpx 维护。
      2.1 adaptation maintained by Gpx.
